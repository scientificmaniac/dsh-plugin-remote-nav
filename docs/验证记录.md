## 3. 真机验证（DSH 桌面端）

- 客户端插件通过重装 bundle 热更新后，HUD 文案立即变为「↑↓←→ 移动 / 长按滚动 · OK 确认 · 返回 退出 · 菜单 切换」（截图：[hud.png](images/hud.png)）。
- 客户端 inspect：`sidebar.footer.action` 中 `remote-nav` occupant 为 `active`，插件行 `fiberPhase: active`。
- 侧边栏底部按钮（截图：[button.png](images/button.png)）与导航高亮在真实界面中可见。

### 验证限制

- DSH 桌面端的本地 Web 服务带访问 token，外部浏览器无法直接连入真机页面做 DOM 断言；
  真机验证采用窗口截图（`PrintWindow`）+ 客户端 inspect 完成。
- 验证期间会话正在生成回答，输入框处于锁定状态，无法在真机直接复现「进入会话后自动聚焦」；
  该场景已在 `demo/behavior.html` 中用相同的 DOM 结构复现并通过，日常使用中继续观察。

## 5. 复验方法

```bash
npm test
npm run demo
# 浏览器打开 http://127.0.0.1:8125/demo/behavior.html
# 或打开 http://127.0.0.1:8125/demo/standalone.html
```

真机复验：

1. 修改 `src/` 后执行 `npm run build`；
2. 用插件管理重新安装本地 bundle（`remove_bundle` → `install_bundle`，或重开 DSH 桌面端）；
3. 在会话里开启导航（`F9` 或侧边栏按钮），按本文第 2 节的场景逐项检查。
